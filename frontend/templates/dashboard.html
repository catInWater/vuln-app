Mission Statement

This laboratory provides a deliberately insecure web application to teach real-world security vulnerabilities through direct, hands-on exploitation. Learn how attacks work, why they happen, and how to defend against them.

Vulnerabilities to Discover
SQLi

SQL Injection

Inject SQL through form inputs to manipulate the underlying database queries.

XSS

Stored XSS

Malicious scripts stored in the database execute for anyone who views the page.

XSS

Reflected XSS

Scripts reflected back from URL parameters execute immediately in the browser.

Session

Session Hijacking

Weak session secrets let you forge or steal another user's session cookie.

Brute

No Rate Limiting

Unlimited login attempts make credential guessing and brute force trivial.

Crypto

Weak Password Storage

Passwords hashed with unsalted MD5 can be reversed with rainbow tables.

Exposed

Exposed Database

The database file is downloadable without any authentication at all.

CSRF

CSRF

Form submissions carry no tokens, allowing cross-site request forgery.
